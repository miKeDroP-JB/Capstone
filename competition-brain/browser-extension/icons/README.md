# Icon Files

Place your icon files here in the following sizes:

- `icon16.png` - 16x16px (toolbar, tabs)
- `icon32.png` - 32x32px (Windows)
- `icon48.png` - 48x48px (extensions page)
- `icon128.png` - 128x128px (Chrome Web Store, installation)

## Generating Icons

You can create icons using:

1. **Design Tools**: Figma, Sketch, Adobe Illustrator
2. **Online Generators**: https://realfavicongenerator.net/
3. **AI Tools**: DALL-E, Midjourney, Stable Diffusion

## Recommended Design

- **Theme**: Brain / Neural Network
- **Colors**: Cyan (#06b6d4) on dark background (#0f172a)
- **Style**: Modern, tech-focused, simple
- **Format**: PNG with transparency

## Quick Generation

Use this SVG as a starting point (save as PNG at required sizes):

```svg
<svg width="128" height="128" xmlns="http://www.w3.org/2000/svg">
  <rect width="128" height="128" fill="#0f172a" rx="16"/>
  <text x="64" y="90" font-size="72" text-anchor="middle" fill="#06b6d4">🧠</text>
</svg>
```

Or use an emoji converter at https://favicon.io/emoji-favicons/brain/
