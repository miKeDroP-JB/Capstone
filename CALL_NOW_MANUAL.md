## 📜 THE EXACT SCRIPT (Use This)

### OPENING (First 15 seconds)
```
"Hi, this is [YOUR NAME]. I help HVAC companies like yours get 20-30%
more customers using AI automation - with zero upfront cost. You only
pay if it works. Do you have 60 seconds?"
```

**If they say "I'm busy":**
```
"I totally understand! This literally takes 90 seconds. Quick question -
biggest challenge right now with getting new customers?"
```

**If they say "Not interested":**
```
"No worries! If anything changes, my number is [YOUR NUMBER]. Have a
great day!"
```

**If they say "Sure" or "What's this about?":**
→ Go to DISCOVERY

---

### DISCOVERY (Find Their Need)

**Ask these 3 questions:**

**Q1:** "What's your biggest challenge right now with getting new customers?"

**Q2:** "How are you currently handling bookings/scheduling?"

**Q3:** "What takes up most of your time that you wish was automated?"

**Listen for needs:**
- "We're still taking calls manually" → Booking system
- "Customer info everywhere" → CRM system
- "No time for marketing" → Marketing automation
- "Customers ask for an app" → Mobile app

**Take notes on what they say!**

---

### PITCH (Offer Solution)

Based on what they said, use this template:

```
"Perfect! I can build you a [THEIR NEED - e.g., booking system] in about
[TIME - e.g., 3 hours].

Here's the deal - normally this would cost $3,000-5,000, but I have a
better model:

I build it for FREE. You pay me nothing upfront.

Then, I get 20% of what it makes you. You keep 80%.

So if this helps you book an extra $10,000 in jobs, you keep $8,000 and
I get $2,000. If it makes you nothing, I get nothing.

Fair?"
```

**If they say "20% is high":**
```
"You know what? For the right partner, I can do 10%. You keep 90%,
I get 10%. Deal?"
```

**If they ask "How much upfront?":**
```
"Zero. That's the beauty of this. I only get paid if it works for you.
You have zero risk."
```

---

### CLOSE (Get Agreement)

```
"Great! Here's what happens next:

1. I build your [solution] this week
2. You review it and we tweak it
3. You start using it
4. You make money
5. We both win

I can start today. Want to do this?"
```

**If they say YES:**
```
"Awesome! Let me get your email and I'll send you a simple agreement.
Should take 2 minutes to sign, then I'll start building.

What's your email?"
```

**If they say "Let me think about it":**
```
"Totally fair. What specifically do you need to know to make a decision?"

[Answer their questions]

"How about this - let me send you a quick 1-page overview via email.
If you like it, we move forward. If not, no worries. Sound good?"
```

## 💡 TIPS FOR SUCCESS

### Mindset
- You're HELPING them, not selling
- You have zero risk offer (free upfront!)
- You're solving real problems
- Rejection = information (not personal)

### Voice
- Confident but friendly
- Speak clearly
- Smile while talking (they can hear it!)
- Pause after questions (let them talk)

### Objection Handling
**"Too expensive"**
→ "Zero upfront. You only pay if it works."

**"I need to think about it"**
→ "What specifically are you unsure about?"

**"We already have someone"**
→ "This supplements them, doesn't replace. Pure upside."

**"Not a good time"**
→ "When would be better? I'll call you then."

### After Each Call
- Take notes immediately
- Update tracking sheet
- Breathe
- Next call
