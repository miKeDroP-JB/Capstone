## 💡 HIRING TIPS

### Finding Talent FAST
1. **Post on multiple platforms simultaneously:**
   - Upwork (best quality)
   - Fiverr (faster, cheaper)
   - OnlineJobs.ph (Philippines VAs)
   - Freelancer.com
   - Reddit r/forhire

2. **Screen quickly:**
   - Voice recording (sales roles)
   - Portfolio + timeline (developers)
   - Test project (small paid test)

3. **Hire fast, fire fast:**
   - Start with 1-week trial
   - Give clear targets
   - Cut if underperforming
   - Always have backups

### Pay Structure
**Sales Callers:**
- Option A: $15/hr + commission (safer)
- Option B: Commission only (higher upside)
- Use Option A for first hires, Option B for scaling

**Developers:**
- Per-project preferred (aligns incentives)
- Don't pay hourly (too slow)
- Bonuses for speed

**VAs:**
- Hourly ($8-12/hr)
- Start low, raise for performers
- Bonus for hitting metrics

### Red Flags
**Sales Callers:**
- ✗ "I need training" (you want experienced)
- ✗ "Can I work part-time?" (need commitment)
- ✗ No sales numbers in application

**Developers:**
- ✗ No portfolio
- ✗ "I need detailed specs" (you want fast movers)
- ✗ Can't start immediately

**VAs:**
- ✗ Poor English
- ✗ Not tech-savvy
- ✗ Can't overlap with US hours

### Green Flags
**Sales:**
- ✓ Specific close rates mentioned
- ✓ Experience with B2B sales
- ✓ Great voice sample
- ✓ Can start immediately

**Developers:**
- ✓ Portfolio of SHIPPED projects
- ✓ "I build fast" in application
- ✓ Mentions deadlines met/beaten
- ✓ Available 30-40 hrs/week

**VAs:**
- ✓ Lists specific tools (Airtable, Stripe, etc.)
- ✓ Detail-oriented application
- ✓ US timezone overlap
- ✓ 2+ years experience
