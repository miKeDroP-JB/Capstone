## Stripe Setup (5 minutes)

### Step 1: Create Account
```
1. Go to https://stripe.com
2. Click "Start now" → "Sign up"
3. Enter:
   - Email
   - Password
   - Business name (your name or company)
4. Verify email
```

### Step 2: Add Business Info
```
1. Go to Settings → Business settings
2. Enter:
   - Business type: Individual or LLC
   - Industry: Software/SaaS
   - Website: (optional, can skip)
3. Add bank account:
   - Routing number
   - Account number
   - Confirm micro-deposits (2-3 days)
```

### Step 3: Create Payment Links
```
1. Go to Payments → Payment links
2. Click "New"
3. Configure:
   - Product: "HVAC AI Voice Agent - Setup Fee"
   - Price: $200 (or custom)
   - Description: "One-time setup fee for AI voice system"
4. Click "Create link"
5. Copy link: https://buy.stripe.com/xxxxx
```

### Step 4: Create Invoice Template
```
1. Go to Invoices → New invoice
2. Save as template:

   INVOICE TEMPLATE:
   ---
   From: Your Name / Company
   Service: AI Voice Agent - Monthly Performance Fee

   Description:
   - Month: [MONTH]
   - Calls made: [X]
   - Appointments booked: [X]
   - Jobs closed: [X]
   - Total job revenue: $[AMOUNT]
   - Performance fee (10%): $[AMOUNT]

   Amount due: $[AMOUNT]
   Payment terms: Net 30
   ---
```

## PayPal Setup (3 minutes)

### Step 1: Create Business Account
```
1. Go to https://paypal.com/business
2. Click "Sign Up"
3. Choose "Business Account"
4. Enter:
   - Email
   - Password
   - Business name
5. Link bank account
```

### Step 2: Create Payment Buttons
```
1. Go to Tools → PayPal Buttons
2. Create button:
   - Type: Buy Now
   - Item: "AI Voice Agent Setup"
   - Price: $200
   - Currency: USD
3. Copy button link
```

### Step 3: Send Invoices
```
1. Go to Send & Request → Create Invoice
2. Template:
   - To: Client email
   - Item: AI Voice Agent - Monthly Fee
   - Amount: $[calculated 10%]
```

## Tax Considerations

**Important:** I'm not a tax professional. Consult a CPA.

**General guidance:**
- Track ALL income (Stripe does this automatically)
- Save 25-30% for taxes (self-employment + income)
- File quarterly estimated taxes (if making $1k+/month)

- Keep records (invoices, receipts, bank statements)

**Get a CPA if:**
- Making $5k+/month consistently

## Common Questions

**"Which payment method should I use?"**
→ Stripe for professional operation, PayPal for quick setup

**"Should I charge setup fee?"**
→ Yes for serious clients. Offer $0 option for those on fence.

**"What if client doesn't pay?"**
→ Send reminder at 15 days, 30 days. Stop service at 45 days.

**"How do I track who owes what?"**
→ Spreadsheet or Stripe dashboard

**"What if client disputes amount?"**
→ Show transparent breakdown of jobs closed. Adjust if error.

**"Can I charge more than 10%?"**
→ Yes, but 10% is industry standard for performance-based

**"Can I charge less?"**
→ Don't undervalue yourself. 10% is already generous.
