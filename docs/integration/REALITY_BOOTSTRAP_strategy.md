## THE RISKS & MITIGATIONS

### Risk 1: Tech Doesn't Work in Time
**Mitigation:**
- Phased tech rollout (don't need full v1.0 for film)
- Film script flexible to match actual progress
- Documentary angle works even if tech is "in progress"
- Authenticity > perfection (building in public shows real journey)

### Risk 2: Film Doesn't Get Distribution
**Mitigation:**
- Self-distribute if needed (YouTube, Vimeo, own platform)
- Tech community IS the audience (built-in distribution)
- Series format backup (episodic release)
- Film festival circuit builds buzz regardless

### Risk 3: Audiences Don't Connect the Dots
**Mitigation:**
- Explicit marketing: "This film has working code"
- QR codes in film linking to GitHub
- Post-credits scene directing to deployment
- Press strategy emphasizes the integration

### Risk 4: Tech Community Sees Film as "Fluff"
**Mitigation:**
- Real code shown in film (not Hollywood fake)
- Technical accuracy vetted by community
- Open-source release proves legitimacy
- Documentary component appeals to technical audience

### Risk 5: Film Community Sees Tech as "Gimmick"
**Mitigation:**
- Story stands alone (tech is context, not crutch)
- Character-driven narrative first, tech second
- Emotional arc doesn't require understanding code
- Tech enhances but doesn't replace storytelling
